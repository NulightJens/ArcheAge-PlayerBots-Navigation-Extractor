## 0.1.0-alpha.1 — 2026-09-14 · Preview

- Extract navigation graphs and plan routes from local ArcheAge 1.2 game data.
- Use recorded walks as optional route preferences.
- Select an extraction area, starting point and destination from the command line.

Requires .NET 10 and a matching built AAEmu/PlayerBots installation.
Check planned routes in game before using them for bots.
